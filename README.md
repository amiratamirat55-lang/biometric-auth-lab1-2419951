2. **Why is a perfect fingerprint system impossible?**
A perfect fingerprint system is impossible because biological traits naturally vary across scans due to changes in finger position, rotation, pressure, and skin dryness or moisture. Additionally, lowering the threshold to accept all genuine users increases false matches (FMR), while raising it to block all impostors increases false rejections (FNMR).

3. **Where could this kind of system be used, and what could go wrong?**
This kind of fingerprint system can be used for unlocking personal smartphones, securing workplace access doors, or verifying identities at border control gates. However, things could go wrong if a user presents a partial, wet, or dirty scan causing a false rejection, or if an attacker uses a spoofed fingerprint to bypass a low-threshold system.
